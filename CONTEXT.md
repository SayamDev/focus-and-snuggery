# Context
Focus & Snuggery is a free, local-first support tool, not medical treatment.
A task is an editable, estimated 2–15 minute action. Effort and current energy use low, medium and high.
Later tasks remain available without penalty. Completing a task is always reversible.
A check-in is a private mood and optional sensory observation, never a diagnosis.
