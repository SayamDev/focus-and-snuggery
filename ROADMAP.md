# Later phases

The current build stays within the supplied MVP. Future work requires explicit scope decisions and participant feedback.

- Social-tone translator: show suggestions as drafts, preserve the user's meaning, offer literal/neutral variants and disclose model limits.
- AAC symbol boards: evaluate Cboard and ARASAAC licences, attribution, accessible symbol navigation and offline caching with AAC users.
- AI body double: opt-in, user-controlled prompts, no autoplay, no pressure or surveillance; preserve an AI-free mode.
- Caregiver summaries: specific, revocable consent, preview every summary, share only explicitly selected data. No automatic external communication.
- Localization: translate interface and safety resources with local reviewers, support RTL, locale-aware voice and culturally appropriate phrasing.
- Broader user testing: neurodivergent participants, assistive technologies, low-memory devices and browser install/offline behavior before public launch.
