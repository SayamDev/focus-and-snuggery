# Local-first storage and optional inference

Accepted: 2026-10-07.
Use IndexedDB through Dexie. Validate complete JSON backups. No accounts or application server.
Use deterministic task splitting by default. Optional WebLLM is activated by a user, with a strict validated output contract, one retry and fallback. Do not download model weights on first launch.
Browser speech recognition is explicitly opted into because its privacy/offline behavior differs from typed input.
